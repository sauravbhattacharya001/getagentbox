Your privacy, protected

We built AgentBox with security and privacy as core principles — not afterthoughts

🏠

Isolated workspaces

Every user gets a private, sandboxed workspace. Your conversations, memory, and files are completely separated from other users — no shared context, no data leakage.

✓ Per-user memory isolation
✓ No cross-user data access
✓ Workspace deletion on request
🔐

Encrypted in transit

All communication between you and your agent is encrypted via TLS. Messages travel through Telegram's encrypted infrastructure — we never see your raw messages on the wire.

✓ TLS 1.3 for all connections
✓ Telegram MTProto encryption
✓ No plaintext message storage
🚫

Never used for training

Your conversations are never used to train AI models. Your data is yours — we don't sell it, share it, or mine it for insights. Period.

✓ Zero training data collection
✓ No third-party data sharing
✓ No behavioral profiling
🎛️

You're in control

Clear your agent's memory anytime. Delete your data permanently. Export your conversations. You decide what your agent remembers — and what it forgets.

✓ One-command memory wipe
✓ Data export on request
✓ Account deletion within 24h
📖

Open source powered

AgentBox is built on OpenClaw, an open-source AI agent framework. Our infrastructure code is auditable — transparency builds trust.

✓ Open-source agent framework
✓ Auditable architecture
✓ Community-reviewed security
📦

Minimal data collection

We collect only what's needed to run your agent — no analytics trackers, no ad networks, no fingerprinting. Our analytics are privacy-friendly and open-source.

✓ GoatCounter analytics (no cookies)
✓ No third-party trackers
✓ No advertising SDK
🔒 TLS Encrypted
🛡️ SOC 2 Aligned
🇪🇺 GDPR Compliant
📜 Open Source

    Frequently asked questions

    Everything you need to know

    Is it really free?

    +

    Yes! You get 20 free messages per day, no credit card required. Just open Telegram and start chatting. If you need more, premium plans are available.

    Do I need to install anything?

    +

    Nope. If you have Telegram (on your phone, desktop, or web), you're ready. Just tap the link, hit Start, and you're talking to your agent.

    How does memory work?

    +

    Your agent maintains a private workspace that persists across conversations. It remembers things you've told it — preferences, past requests, context — so you never have to repeat yourself.

    Is my data private?

    +

    Each user gets their own isolated workspace. Your conversations and data aren't shared with other users or used to train models. Your agent is yours.

    What AI model does it use?

    +

    AgentBox uses state-of-the-art language models (including GPT-4o and Claude) with vision capabilities. It can understand text, images, voice, and search the web for real-time information.

    What can I actually use it for?

    +

    Anything you'd ask a smart assistant — research, writing help, coding questions, recipe ideas, reminders, image analysis, travel planning, quick calculations, language translation, and more. It's surprisingly versatile.

    Can I use it in group chats?

    +

    Currently AgentBox works best in direct messages. Group chat support is on the roadmap — stay tuned!
