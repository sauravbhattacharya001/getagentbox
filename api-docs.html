🔑 Authentication

All API requests require a Bearer token. Get your API key from the AgentBox Dashboard.

Header
Authorization: Bearer ab_live_xxxxxxxxxxxxxxxxxxxx

⚠️ Keep your API key secret. Never expose it in client-side code. Use environment variables or a secrets manager.

Base URL

https://api.getagentbox.com/v1

All endpoints below are relative to this base URL.

Endpoints

POST /messages

Send a message to your AI agent and get a response. Supports text, images, and file attachments.

Parameters

NameTypeDescription
message string required The message text to send
conversation_id string optional Continue an existing conversation. Omit to start new.
attachments array optional Array of base64-encoded files with type and data fields
stream boolean optional Enable Server-Sent Events streaming (default: false)
Request
curl -X POST https://api.getagentbox.com/v1/messages \
  -H "Authorization: Bearer ab_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "What meetings do I have tomorrow?",
    "conversation_id": "conv_abc123"
  }'
Response — 200 OK
{
  "id": "msg_7f3k9x",
  "conversation_id": "conv_abc123",
  "role": "assistant",
  "content": "You have 2 meetings tomorrow:\n• 10:00 AM — Team standup\n• 2:00 PM — Design review with Sarah",
  "tokens_used": 142,
  "created_at": "2026-03-22T15:30:00Z"
}

GET /conversations

List all conversations, sorted by most recent. Supports pagination.

Query Parameters

NameTypeDescription
limit integer optional Number of results (default: 20, max: 100)
cursor string optional Pagination cursor from previous response
Response — 200 OK
{
  "data": [
    {
      "id": "conv_abc123",
      "last_message": "You have 2 meetings tomorrow...",
      "message_count": 14,
      "updated_at": "2026-03-22T15:30:00Z"
    }
  ],
  "has_more": true,
  "next_cursor": "cur_xyz789"
}
POST /memories

Store a memory that the agent will reference in future conversations.

NameTypeDescription
content string required The memory to store (e.g. "User prefers dark mode")
category string optional Category tag: preference, fact, reminder, context
Request
curl -X POST https://api.getagentbox.com/v1/memories \
  -H "Authorization: Bearer ab_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "User is vegetarian and allergic to nuts",
    "category": "preference"
  }'
Response — 201 Created
{
  "id": "mem_9g8h7i",
  "content": "User is vegetarian and allergic to nuts",
  "category": "preference",
  "created_at": "2026-03-22T16:00:00Z"
}
GET /memories

List all stored memories for the authenticated user. Filter by category.

Request
curl "https://api.getagentbox.com/v1/memories?category=preference" \
  -H "Authorization: Bearer ab_live_xxx"
Response — 200 OK
{
  "data": [
    {
      "id": "mem_9g8h7i",
      "content": "User is vegetarian and allergic to nuts",
      "category": "preference",
      "created_at": "2026-03-22T16:00:00Z"
    }
  ],
  "total": 1
}

🔔 Webhooks

Receive real-time notifications when events occur. Configure webhook URLs in your dashboard.

Available Events

EventDescription
message.createdNew message in a conversation
conversation.createdNew conversation started
memory.createdNew memory stored
reminder.triggeredA scheduled reminder fired
Webhook Payload
{
  "event": "message.created",
  "timestamp": "2026-03-22T15:30:00Z",
  "data": {
    "id": "msg_7f3k9x",
    "conversation_id": "conv_abc123",
    "role": "assistant",
    "content": "You have 2 meetings tomorrow..."
  }
}

Webhook requests include an X-AgentBox-Signature header for verification. Validate using HMAC-SHA256 with your webhook secret.

⚠️ Error Handling

All errors follow a consistent format:

{
  "error": {
    "code": "rate_limit_exceeded",
    "message": "You've exceeded your hourly rate limit. Try again in 42 seconds.",
    "retry_after": 42
  }
}
StatusCodeDescription
400invalid_requestMissing or invalid parameters
401unauthorizedInvalid or missing API key
403forbiddenAPI key lacks required permissions
404not_foundResource doesn't exist
429rate_limit_exceededToo many requests
500internal_errorSomething went wrong on our end

Quick Start — Python

from agentbox import AgentBox

client = AgentBox(api_key="ab_live_xxx")

response = client.messages.send(
    message="Summarize my unread emails",
    conversation_id="conv_abc123"  # optional
)

print(response.content)

Quick Start — Node.js

import { AgentBox } from '@agentbox/sdk';

const client = new AgentBox({ apiKey: 'ab_live_xxx' });

const response = await client.messages.send({
  message: 'Summarize my unread emails',
  conversationId: 'conv_abc123'
});

console.log(response.content);
