Authentication

All API requests require a Bearer token in the Authorization header. Generate your API key at Settings → API Keys in your AgentBox dashboard. Keep your key secret — treat it like a password.

Endpoints

MethodEndpointDescription
POST /v1/messages Send a message to your agent
GET /v1/messages List recent messages (paginated)
GET /v1/agent/status Get agent status & metadata
POST /v1/memory/search Semantic search through agent memory
GET /v1/memory List memory entries
DELETE /v1/memory/:id Delete a specific memory
GET /v1/usage Get usage statistics & quota
POST /v1/webhooks Register a webhook endpoint

Quick Start

Send a Message

curl -X POST https://api.getagentbox.com/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"message": "What meetings do I have tomorrow?"}'

Search Agent Memory

curl -X POST https://api.getagentbox.com/v1/memory/search \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "project deadlines", "limit": 5}'

Check Usage & Quota

curl https://api.getagentbox.com/v1/usage \
  -H "Authorization: Bearer YOUR_API_KEY"
