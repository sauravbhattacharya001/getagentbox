Design Philosophy

Zero dependencies. No npm, no build step, no bundler. The site loads two JS files and a CSS file. That's it.
Progressive enhancement. Core content is static HTML. JavaScript adds interactivity, animations, and dynamic sections. The page is usable without JS.
Lazy everything. Modules initialize only when their section scrolls into view via IntersectionObserver. First paint is fast.
Self-contained modules. Each IIFE owns its DOM, state, and event listeners. No global variables leak. Modules communicate through the public API they return.

IIFE Module Pattern

Every module follows the same structure:

var ModuleName = (function () {
  // ── Private state ──────────────────────────
  var _cache = null;
  var _isInit = false;

  // ── Private functions ──────────────────────
  function _helper() { /* ... */ }

  // ── Public API ─────────────────────────────
  function init() {
    var section = document.getElementById('sectionId');
    if (!section) return;
    // Bind events, build DOM, etc.
  }

  function destroy() {
    // Clean up event listeners, timers
  }

  // ── Expose ─────────────────────────────────
  return {
    init: init,
    destroy: destroy,
    // Test-friendly getters
    getCurrent: function () { return _cache; }
  };
})();

Key conventions:

  • Use var (not const/let) for broad compatibility
  • Use function declarations (not arrow functions)
  • Every module has an init() that guards with if (!section) return
  • Expose test-friendly getters (e.g. getCurrent, getTotal)
  • Duplicate utility functions (like escapeHtml) per module — each IIFE is standalone

Lazy Initialization

Modules are registered with lazyInit(sectionId, initFn) which uses a shared IntersectionObserver. When a section enters the viewport, its init() runs once.

// Registration (in the DOMContentLoaded block)
lazyInit('statsSection', function () { Stats.init(); });
lazyInit('integrationsSection', function () { Integrations.init(); });

// Implementation
function lazyInit(sectionId, initFn) {
  var el = document.getElementById(sectionId);
  if (!el) { initFn(); return; }   // fallback: init immediately
  _lazyInitQueue.push({ el: el, fn: initFn, done: false });
}

function startLazyObserver() {
  _lazyObserver = new IntersectionObserver(function (entries) {
    entries.forEach(function (entry) {
      if (entry.isIntersecting) {
        // Find and run the matching init
      }
    });
  }, { rootMargin: '200px' });   // 200px ahead of viewport
}

Accessibility Patterns

Two shared helper functions handle keyboard navigation across all modules:

// Arrow key navigation within a container
arrowKeyNav(container, selector, onNavigate)
// Enter/Space activation
activateOnKeyboard(container, selector, onActivate)

All interactive elements use ARIA attributes: role, aria-pressed, aria-expanded, aria-checked, tabindex. The AccessibilityPanel module provides user-configurable preferences.

Testing

Tests use Jest with jsdom. Each test file evaluates app.js in a fresh DOM context. Test categories:

  • Functional tests — Module behavior, event handling, state management
  • Security tests — localStorage validation, escapeHtml, input limits
  • Performance tests — DOM caching, scoped queries, no unnecessary re-queries
  • Accessibility tests — ARIA attributes, keyboard navigation, focus management
# Run all tests
npx jest

# Run a specific test file
npx jest __tests__/security.test.js

# With coverage
npx jest --coverage

Code Conventions

  • var over const/let — broader compatibility, consistent style
  • function declarations over arrow functions
  • Section dividers: // ── Section Name ────────────
  • JSDoc comments for complex functions
  • Guard clauses: if (!section) return; at top of init()
  • DOM queries: scope to section element, not document
  • Event cleanup: provide destroy() for modules with global listeners
  • No external imports — everything is vanilla JS

Adding a New Module

  1. Add HTML section to index.html with a unique id
  2. Add styles to styles.css (prefix classes with module name)
  3. Add IIFE to app.js following the pattern above
  4. Register with lazyInit('sectionId', function () { Module.init(); })
  5. If rendering user content, add a local escapeHtml()
  6. If using localStorage, use Object.create(null) for parsed objects
  7. Add test file in __tests__/
  8. Update docs/modules.md with the new module
