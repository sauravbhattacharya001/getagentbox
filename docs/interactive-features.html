🎬 Scenario Planner

Animates a multi-phase task breakdown showing how AgentBox plans, executes, and delivers on complex real-world requests. Each scenario walks through Understand → Plan → Execute → Deliver phases with typing-animated steps.

Data Model

SCENARIOS = {
  "Plan a surprise birthday dinner for 8 people...": {
    phases: [
      { icon: '🔍', name: 'Understand', steps: [...] },
      { icon: '📋', name: 'Plan',       steps: [...] },
      { icon: '⚡', name: 'Execute',    steps: [...] },
      { icon: '✅', name: 'Deliver',    steps: [...] }
    ]
  }
  // ... more scenarios
}

Public API

ScenarioPlanner.init()

Binds event listeners, renders the scenario selector, and initializes the animation controller. Call once after DOM ready.

ScenarioPlanner.run(scenarioKey)

Starts the multi-phase animation for a given scenario. Each step is revealed with configurable delay (ms).

How It Works

  1. User selects a scenario from the dropdown
  2. Each phase renders sequentially with progress indicators
  3. Steps within each phase animate with typing delays (400–900ms)
  4. A final "deliverable" card appears with the completed plan

⏱️ Speed Challenge

Side-by-side race comparing traditional web search (7 steps, ~10.5s) vs AgentBox (3 steps, ~1.5s). Demonstrates the value proposition through interactive timing.

How It Works

  1. User selects a trivia question (e.g. "What's the capital of Bhutan?")
  2. Two columns animate simultaneously:
    • Traditional: Open browser → Navigate → Type → Scan → Click → Read → Find (7 steps)
    • Agent: Send message → Processing → Answer ready (3 steps)
  3. Timer shows elapsed time; agent finishes ~7× faster
  4. Final answer displays with the time comparison

Preset Questions

ANSWERS = {
  "What's the capital of Bhutan?": "Thimphu is the capital of Bhutan.",
  "Convert 72°F to Celsius": "72°F = 22.2°C",
  "Who painted the Mona Lisa?": "Leonardo da Vinci (c. 1503–1519).",
  "How many ounces in a gallon?": "128 fluid ounces in a US gallon.",
  "What year did the Berlin Wall fall?": "November 9, 1989."
}

✅ Setup Checklist

Interactive onboarding progress tracker that guides new users through the AgentBox setup process. Progress is persisted to localStorage.

Steps

  1. Install Telegram — Link to telegram.org/apps
  2. Find @AgentBoxBot — Direct link to t.me/AgentBoxBot
  3. Send /start — Initialize the bot
  4. Try Your First Prompt — Suggested starter prompts
  5. Enable Memory — Turn on conversation memory
  6. Set a Reminder — Test scheduling features
  7. Explore /help — Discover all commands

When all steps are completed, a celebration animation plays and a "Setup Complete" badge appears.

Storage

Key: agentbox_setup_checklist. Stores an array of completed step IDs.

🏗️ Module Pattern

All interactive features follow the same IIFE (Immediately Invoked Function Expression) pattern for encapsulation without build tools:

var ModuleName = (function () {
  'use strict';

  // Private state
  var CONSTANTS = { ... };
  var _state = null;

  // Private methods
  function _render() { ... }

  // Public API
  function init() {
    // Bind to DOM, set up events
  }

  return { init: init };
})();

Conventions

  • Private variables prefixed with _
  • Constants in UPPER_SNAKE_CASE
  • All modules expose at minimum an init() method
  • DOM queries are lazily cached for performance
  • No external dependencies — pure vanilla JS

💾 Storage Layer

The shared StorageUtil module (loaded first in build order) provides safe localStorage access with automatic JSON serialization and fallback for private browsing:

StorageUtil.get(key, fallback)

Returns parsed JSON value or fallback if missing/corrupt.

StorageUtil.set(key, value)

JSON-serializes and stores the value. Silently fails in private mode.

StorageUtil.remove(key)

Removes a key from storage.

🔧 Adding New Interactive Features

  1. Create src/modules/your-feature.js following the IIFE pattern above
  2. Add a corresponding section in the landing page HTML with unique IDs
  3. Register initialization in src/modules/init.js: 
    if (document.getElementById('yourFeatureSection')) {
  YourFeature.init();
}
  4. Add to build.js source list (order matters — dependencies first)
  5. If using persistence, namespace your key as agentbox_your_feature
  6. Run node build.js to regenerate dist/bundle.js
  7. Add tests in __tests__/ following existing patterns

See the Plugin Development Guide for the full plugin lifecycle and event system.
