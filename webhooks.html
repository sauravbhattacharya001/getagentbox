🔗 Webhooks

Receive real-time events from your AgentBox agent. Build automations, log activity, or connect to your own systems.

Quick Start

Set up webhooks in three simple steps:

  1. Create an endpoint — set up an HTTPS URL that accepts POST requests on your server.
  2. Register the webhook — tell AgentBox where to send events using the /webhook command in Telegram or the API.
  3. Handle events — parse the JSON payload and respond with a 200 status code within 10 seconds.

Available Events

Subscribe to any combination of these events:

message.received
Fired when the agent receives a new message from the user.
message.sent
Fired when the agent sends a response back to the user.
reminder.triggered
Fired when a scheduled reminder activates.
memory.updated
Fired when the agent updates its long-term memory about the user.
task.completed
Fired when a background task (web search, file processing) finishes.
session.started
Fired when a new conversation session begins.
session.ended
Fired when a conversation session ends due to inactivity or user action.
quota.warning
Fired when the user approaches their daily message limit (80% used).

Payload Format

All webhook payloads follow the same structure:

{
  "id": "evt_abc123def456",
  "event": "message.received",
  "timestamp": "2026-03-25T18:30:00Z",
  "data": {
    "user_id": "u_789",
    "session_id": "sess_012",
    "content": "Remind me to call the vet tomorrow at 3pm",
    "metadata": {
      "channel": "telegram",
      "message_id": "msg_345"
    }
  }
}

Event-Specific Data

reminder.triggered includes:

{
  "event": "reminder.triggered",
  "data": {
    "reminder_id": "rem_678",
    "user_id": "u_789",
    "text": "Call the vet",
    "scheduled_at": "2026-03-26T15:00:00Z",
    "created_at": "2026-03-25T18:30:00Z"
  }
}

task.completed includes:

{
  "event": "task.completed",
  "data": {
    "task_id": "tsk_901",
    "type": "web_search",
    "user_id": "u_789",
    "result_summary": "Found 5 results for 'best restaurants Seattle'",
    "duration_ms": 2340
  }
}

Setup via API

POST /api/v1/webhooks
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "url": "https://yourserver.com/agentbox-webhook",
  "events": ["message.received", "reminder.triggered"],
  "secret": "whsec_your_signing_secret"
}

Or use the Telegram command:

/webhook add https://yourserver.com/agentbox-webhook message.received,reminder.triggered

Code Examples

Node.js (Express)

const express = require('express');
const crypto = require('crypto');
const app = express();

app.use(express.json());

function verifySignature(req, secret) {
  const signature = req.headers['x-agentbox-signature'];
  const timestamp = req.headers['x-agentbox-timestamp'];
  const body = JSON.stringify(req.body);
  const expected = crypto
    .createHmac('sha256', secret)
    .update(timestamp + '.' + body)
    .digest('hex');
  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expected)
  );
}

app.post('/agentbox-webhook', (req, res) => {
  if (!verifySignature(req, 'whsec_your_secret')) {
    return res.status(401).send('Invalid signature');
  }

  const { event, data } = req.body;
  console.log(`Received ${event}:`, data);

  switch (event) {
    case 'message.received':
      console.log(`User said: ${data.content}`);
      break;
    case 'reminder.triggered':
      console.log(`Reminder: ${data.text}`);
      break;
  }

  res.status(200).json({ ok: true });
});

app.listen(3000);

Python (Flask)

import hmac, hashlib, json
from flask import Flask, request, jsonify

app = Flask(__name__)
SECRET = 'whsec_your_secret'

def verify_signature(req):
    signature = req.headers.get('X-AgentBox-Signature', '')
    timestamp = req.headers.get('X-AgentBox-Timestamp', '')
    body = req.get_data(as_text=True)
    expected = hmac.new(
        SECRET.encode(),
        f'{timestamp}.{body}'.encode(),
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(signature, expected)

@app.route('/agentbox-webhook', methods=['POST'])
def webhook():
    if not verify_signature(request):
        return jsonify(error='Invalid signature'), 401

    event = request.json['event']
    data = request.json['data']
    print(f'Received {event}: {data}')

    return jsonify(ok=True), 200

🔒 Security Best Practices

• Always verify signatures — use the X-AgentBox-Signature header with your signing secret to verify payloads are authentic.

• Use HTTPS only — webhook URLs must use HTTPS. HTTP endpoints are rejected.

• Respond quickly — return a 200 status within 10 seconds. For long processing, acknowledge immediately and handle asynchronously.

• Handle retries — failed deliveries are retried 3 times with exponential backoff (10s, 60s, 300s). Use the event id field to deduplicate.

• Rotate secrets — you can rotate your signing secret anytime via /webhook rotate-secret. Both old and new secrets are valid for 24 hours during rotation.

Rate Limits

Webhooks are subject to the following limits:

• Delivery rate: up to 100 events per minute per endpoint.

• Max endpoints: 5 webhook URLs per account.

• Payload size: max 64 KB per event.

• Retry policy: 3 attempts with exponential backoff. After 3 failures, the webhook is disabled and you're notified via Telegram.
