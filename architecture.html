User Interface

📱 Telegram Bot Gateway

  • Receives user messages via Telegram Bot API (webhook or long-poll)
  • Supports text, images, voice, documents, and inline buttons
  • Handles message formatting, reactions, and reply threading
  • Delivers AI responses back to the user's chat in real-time

🔀 API Gateway

  • Authenticates users and validates bot tokens
  • Rate limits requests to prevent abuse (per-user quotas)
  • Routes messages to the correct AI session
  • Manages WebSocket connections for real-time updates
  • Handles graceful degradation when downstream services are slow

🧠 AI Engine

  • Orchestrates LLM calls with context injection (memory, persona, tools)
  • Manages conversation history with intelligent truncation
  • Selects and calls tools (web search, code execution, file I/O)
  • Applies safety guardrails and content filtering
  • Supports multiple LLM providers with automatic failover
  • Handles streaming responses for faster perceived latency

💾 Memory Store

  • Per-user persistent memory with semantic search
  • Stores preferences, facts, conversation highlights
  • Curated long-term memory (MEMORY.md) vs. daily notes
  • Vector-indexed for fast relevance retrieval
  • Privacy-first: each user's data is fully isolated

⚡ Skill Engine

  • Modular skill system — each skill defines tools, prompts, and scripts
  • Built-in skills: web search, weather, image understanding, code execution
  • Community skill marketplace for extending capabilities
  • Skills can access browser, files, shell, and external APIs
  • Sandboxed execution with permission controls

⏰ Scheduler

  • Cron-based task scheduling with human-friendly syntax
  • One-shot reminders ("remind me in 2 hours")
  • Heartbeat system for proactive check-ins
  • Background sub-agent spawning for long-running tasks
  • Automatic retry with exponential backoff on failures

🌐 Web Search

  • Brave Search API integration for real-time web results
  • Page fetching with automatic content extraction (HTML → readable text)
  • Region and language-aware search results
  • Freshness filters for time-sensitive queries

🤖 LLM Provider

  • Supports Claude (Anthropic), GPT (OpenAI), and other providers
  • Configurable per-session model selection and overrides
  • Extended thinking / reasoning mode support
  • Automatic token budget management and context windowing
  • Fallback to alternative models on rate limits or outages

How a Message Flows

1

User Sends Message

You type in Telegram. The bot receives your message via webhook.

2

Gateway Authenticates

Your identity is verified, rate limits checked, session resolved.

3

Context Assembly

Memory is searched, persona loaded, recent history gathered.

4

AI Thinks

The LLM processes your message with full context and available tools.

5

Tools Execute

If needed, the AI searches the web, checks your calendar, runs code, etc.

6

Response Delivered

The response streams back to your Telegram chat in real-time.
